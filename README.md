## 🌟 Overview

**AvPocket** is an all-in-one ecosystem designed specifically for the **PocketMine-MP (Minecraft: Bedrock Edition)** developer and server-owner community. It bridges the gap between open-source sharing, automated CI/Phar building, and a secure commercial marketplace for Minecraft assets.

---

## 🚀 Key Features

### 📦 Asset & Digital Marketplace
- **Plugins (`.phar` & Source):** Free, open-source, and commercial plugins with automated API version verification.
- **Virions & PHP Libraries:** Native support for PocketMine virions with automatic dependency injection.
- **Maps & Schematics:** Bedrock world downloads, spawn arenas, minigames (BedWars, SkyBlock, Factions).
- **Custom Models & Animations:** Blockbench (`.geo.json`) models and entity animations for custom server setups.
- **Server Bundles & Setups:** Complete pre-configured server packages ready for instant deployment.

### 🛠️ Developer & CI Experience
- **GitHub Integration:** Connect your GitHub repositories to auto-build `.phar` releases upon tags or pushes.
- **`plugin.yml` Inspector:** Auto-extracts target PMMP API, commands, permissions, and dependencies upon upload.
- **Markdown Showcase:** Live rendering of `README.md`, changelogs, and documentation.
- **Release Channels:** Support for Stable, Beta, and Nightly/Dev builds.

### 🛡️ Safety & Quality Assurance
- **Malware & Backdoor Scanner:** Automated PHP code analyzer to detect suspicious calls, token stealers, and unapproved webhooks.
- **Review Queue:** Community and admin review systems to ensure stability and trust.
